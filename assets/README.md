# assets — imagens do dashboard

Coloque aqui os arquivos com estes **nomes exatos** (.jpg):

| Arquivo | O que é |
|---|---|
| `sector-steel.jpg`  | fundo do card **Steel** (siderurgia / metal incandescente) |
| `sector-pp.jpg`     | fundo do card **Pulp & Paper** (floresta / folhas) |
| `team-daniel.jpg`   | foto do **Daniel Sasson** |
| `team-edgard.jpg`   | foto do **Edgard Pinto Souza** |
| `team-marcelo.jpg`  | foto do **Marcelo Furlan** |
| `team-joao.jpg`     | foto do **João Paulo Helito** (quando chegar) |

Referenciados em `index.html` (`assets/...`). Enquanto um arquivo não existe, o card mostra
um gradiente e o avatar mostra as iniciais (fallback). Ideal: imagens já redimensionadas p/
web (fotos ~400px, cards ~800px de largura).
